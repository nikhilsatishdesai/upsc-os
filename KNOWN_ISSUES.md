## Accepted limitations (by design in V1)

- **Single-device data:** all data lives in this browser. Clearing browser data erases progress — use Settings → Export backup regularly. Cloud sync arrives in V5.
- **No accounts:** anyone with access to the device can open the app. Auth arrives in V5.
- **End-to-end (browser automation) tests deferred to V5** when auth flows arrive; V1 ships with unit + data-integrity tests plus a founder manual test checklist.
